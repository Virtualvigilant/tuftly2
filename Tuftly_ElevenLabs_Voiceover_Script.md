## Recommended ElevenLabs v3 / v4 Settings
- **Model:** **Eleven v3**, **Eleven v4**, or **Eleven v4 Turbo** *(required for `[audio tags]`)*
- **Stability / Expressiveness:** Set Stability around **`40% – 50%`** *(or select **Natural / Creative** preset in v3/v4 so the voice responds expressively to the bracketed cues)*
- **Speed:** `1.03x – 1.05x` *(keeps the 30s WhatsApp Status cuts finishing cleanly around `28.5s–29.5s`)*
